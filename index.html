Overview

Aim

This analysis demonstrates a reproducible workflow for quantitative temporal proteomics data,

The main objectives are to:

  1. Import and preprocess quantitative proteomics data.
  2. Identify and assess quantitative protein abundance measurements.
  3. Evaluate missing values and sample quality.
  4. Explore sample relationships using correlation analysis and PCA.
  5. Identify differentially abundant proteins using limma.
  6. Visualize differential protein abundance using volcano plots.
  7. Compare significant protein sets across multiple time points.

The analysis focuses on a time-course experiment containing control and treatment conditions measured at 30 minutes, 1 hour, 2 hours, and 4 hours.

3. Identify quantitative protein measurements

The quantitative abundance columns are identified based on the presence of “Normalized” in their names. The protein abundances normalized by Proteome Discoverer. However, unnormalized abundances can be imported and normalized usign a wished method.

find_quan <- function(df) {

  quan_columns <- character()

  for (cname in colnames(df)) {

    if (grepl("Normalized", cname)) {
      quan_columns <- c(quan_columns, cname)
    }

  }

  return(quan_columns)
}

9. Principal Component Analysis

Principal Component Analysis (PCA) is used to investigate the major sources of variation within the proteomic dataset.
